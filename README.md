# AI Face Emotion Detection using MATLAB

This project is an AI-based facial expression detection system developed using MATLAB, CNN, and VGG16 transfer learning. The system detects human emotions from facial images and real-time webcam input.

## Features

* Real-time webcam emotion detection
* CNN-based emotion classification
* VGG16 transfer learning
* MATLAB GUI support
* FER-2013 dataset integration

## Technologies Used

* MATLAB
* CNN
* VGG16
* Deep Learning Toolbox
* FER-2013 Dataset

## Emotions Detected

* Happy
* Sad
* Angry
* Fear
* Disgust
* Surprise
* Neutral

## System Workflow

1. Image Acquisition
2. Preprocessing
3. Feature Extraction
4. CNN-based Emotion Classification
5. Emotion Detection Output

## Model Performance

The model achieved approximately 92.86% accuracy on the FER-2013 dataset.

## Dataset

This project uses the FER-2013 facial expression dataset from Kaggle.

Dataset Link:
https://www.kaggle.com/datasets/msambare/fer2013

Real-time webcam emotion detection with confidence scores.
